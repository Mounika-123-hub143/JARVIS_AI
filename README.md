# 🤖 JARVIS AI - Voice Assistant

Hi, I'm Mouni! 👋
This is my first Python project - JARVIS, my own Voice Assistant.

## ✨ What JARVIS Can Do
- 🎙️ Listen to my voice
- 🗣️ Speak back to me
- 🌐 Open YouTube, Google
- ⏰ Tell Time & Date
- 😍 Call me "Mouni"

## 🛠️ Made With
- Python
- speech_recognition
- pyttsx3
- sounddevice

## 🚀 How To Run
pip install pyttsx3 speech_recognition sounddevice numpy
python main.py
